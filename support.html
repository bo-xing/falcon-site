Support

Updated September 5, 2026

Falcon is a native iPerf3 and iPerf2 throughput tester for iPhone, iPad, and Mac. The answers below reflect the current Connect, Listen, and SSH workflows.

Contact

Email: boxing.falcon.support@gmail.com

For faster troubleshooting, include the Falcon version, device model and OS version, iPerf engine, test direction and protocol, target address with the sensitive parts removed, and whether you used Connect, Listen, or SSH.

Frequently asked questions

Why does a test fail to connect?

In Connect mode, the other device must already be running a compatible iPerf server. Check the host, port, firewall, and network reachability. iPerf3 and iPerf2 do not interoperate, so the engine must match on both ends. Common defaults are port 5201 for iPerf3 and 5001 for iPerf2.

Can Falcon act as the server?

Yes. Choose Listen, select the interface and port, then start the server. Falcon shows the address another device should connect to and can accept repeated client sessions, saving each completed session separately until you stop listening.

How do the public servers work?

Falcon includes a directory of independently operated public iPerf3 servers. They are convenient for quick checks, but Falcon does not operate them or guarantee their capacity, privacy practices, supported ports, or availability. Respect the operator’s limits, and use your own server for controlled or sensitive testing.

What is included for free, and what does Falcon Pro add?

The free version supports manual TCP and UDP tests, upload, download and bidirectional testing, local server mode, live results, history, and individual CSV/JSON exports and share cards. Falcon Pro is a one-time purchase that adds SSH orchestration, advanced graphical and command-line configuration with saved commands, built-in scenarios and custom presets, saved targets and SSH peers, comparison of up to six runs, and batch export.

What does SSH orchestration do?

Falcon can connect to OpenWrt, Linux, or another SSH host, detect the available iPerf engine, start the remote endpoint, run the test, and clean up afterward. It supports password, OpenSSH private-key, and explicitly configured no-credential access. Host keys are verified using trust on first use (TOFU).

Why is jitter or packet loss missing from a UDP result?

Those metrics come from the receiving side’s report. Some engine and direction combinations—especially certain iPerf2 UDP runs—do not return that report. Falcon then shows a dash or an explanatory note; the throughput shown still reflects the sender-side rate.

Where are results and SSH credentials stored?

Test history, notes, presets, commands, and targets remain in local app storage. On Apple platforms, SSH passwords and private keys are stored in the system Keychain. Falcon has no account system and does not send this data to the developer. See the Privacy Policy for details.

How do I restore Falcon Pro?

Open Settings, choose Falcon Pro, and select Restore Purchases. Use the same Apple Account that made the original purchase. If the entitlement still does not appear, confirm that App Store purchases are available on the device, then contact us with the error message.

Which systems and languages are supported?

The current Apple release supports iOS and iPadOS 17 or later, plus macOS 14 or later on Apple silicon. The interface is available in Simplified Chinese, Traditional Chinese, English, Japanese, Korean, German, French, Spanish, and Russian.
