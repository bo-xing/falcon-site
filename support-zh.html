Falcon 是面向 iPhone、iPad 与 Mac 的原生 iPerf3 / iPerf2 网络吞吐测试工具。以下内容已按当前的「连接」「监听」和「SSH」工作流更新。

常见问题

为什么测试连不上？

在「连接」模式下，对端必须已经运行兼容的 iPerf 服务端。请检查主机、端口、防火墙和网络可达性。iPerf3 与 iPerf2 不能互通，两端必须使用同一引擎；常见默认端口分别是 iPerf3 的 5201 和 iPerf2 的 5001。

Falcon 可以让本机作为服务端吗？

可以。选择「监听」，设定网络接口与端口后启动服务。Falcon 会显示其他设备应连接的地址，并可持续接受多次客户端连接；在你停止监听前，每次完成的会话都会单独保存。

内置公共服务器是怎么回事？

Falcon 收录了由第三方独立运营的公共 iPerf3 服务器，适合快速检查。Falcon 不运营这些服务器，也无法保证其容量、隐私实践、支持端口或可用性。请遵守运营方的限制；如需受控测试或传输敏感流量，请使用你自己的服务端。

免费版包含什么？Falcon Pro 又增加什么？

免费版支持手动 TCP / UDP 测试、上传 / 下载 / 双向测速、本机服务端、实时结果、历史记录，以及单条 CSV / JSON 导出与分享卡片。Falcon Pro 为一次性购买，额外提供 SSH 编排、高级图形与命令行配置和命令收藏、内置场景与自定义预设、常用目标与 SSH 对端保存、最多六条结果对比和批量导出。

SSH 编排具体做什么？

Falcon 可连接 OpenWrt、Linux 或其他 SSH 主机，检测可用的 iPerf 引擎，自动启动远端、运行测试并在结束后清理。支持密码、OpenSSH 私钥，以及明确配置的无凭据访问；主机密钥采用首次使用信任（TOFU）方式校验。

为什么 UDP 结果没有抖动或丢包？

这些指标来自接收端报告。部分引擎与方向组合——尤其是某些 iPerf2 UDP 测试——不会返回这份报告。此时 Falcon 会显示「—」或解释提示；吞吐速度仍按发送端口径显示。

结果与 SSH 凭据存在哪里？

测试历史、备注、预设、命令和目标都保存在应用本地。在 Apple 平台上，SSH 密码与私钥存入系统钥匙串。Falcon 没有账号体系，也不会把这些数据发送给开发者。详见隐私政策。

如何恢复 Falcon Pro？

打开「设置」，进入 Falcon Pro，然后选择「恢复购买」。请使用完成原始购买的同一 Apple 账户。如果权益仍未恢复，请先确认设备可正常使用 App Store 购买服务，再把错误提示发给我们。

支持哪些系统与语言？

当前 Apple 版本支持 iOS / iPadOS 17 及以上，以及运行在 Apple 芯片上的 macOS 14 及以上。界面支持简体中文、繁體中文、English、日本語、한국어、Deutsch、Français、Español 与 Русский。
