隐私政策

最后更新：2026 年 9 月 26 日

本隐私政策说明由个人开发者 Bo Xing 开发与发布的 iPerf Falcon（以下简称「Falcon」或「本应用」）在你使用应用或本支持网站时如何处理信息。

简要说明：Falcon 没有账号体系，不含广告、分析或追踪。本应用不会自动把你的测试历史、保存的目标、命令或 SSH 凭据传输给开发者。

1. 保存在设备上的数据

Falcon 会在设备本地保存实现功能所需的信息：

  • 测试结果与历史：吞吐采样、指标、测试配置、时间、备注及保存的结果。
  • 配置：应用偏好、最近使用和保存的目标、自定义预设、命令收藏、SSH 对端信息，以及用于判断何时可以请求系统评分提示的本地计数。
  • Apple 平台上的 SSH 安全数据：密码与私钥存入系统钥匙串（Keychain）；用于首次使用信任（TOFU）校验的已知主机密钥保存在应用本地容器中。凭据不会存入测试历史数据库。

Falcon 不会把这些数据上传给开发者，也不会通过 Falcon 账号同步。

2. 由你发起的网络连接

网络测试必然会收发流量。只有当你启动端口检查、客户端测试、本机服务端或 SSH 编排测试时，Falcon 才会连接你选择的地址。目标设备、网络运营方和互联网服务提供商可能看到连接元数据与测试流量。

如果选择 Falcon 公共服务器目录中的节点，你连接的是由第三方独立运营的服务器。Falcon 不控制这些服务器及其日志与隐私实践。请勿通过公共测试服务器发送敏感内容。

Falcon 不会把测试内容、历史、凭据或使用分析发送到开发者运营的服务器。

3. App Store 服务与购买

Falcon Pro 通过 Apple 的 App 内购买一次性提供。产品信息、支付、权益校验与恢复购买由 Apple 的 StoreKit 服务处理。开发者不会收到你的完整支付卡信息。Apple 依据其 App Store 与隐私说明和隐私政策处理相关信息。

如果你选择前往 App Store 评分或产品页，本应用会打开 Apple 服务；该处的信息处理适用 Apple 的政策。

4. 导出、分享与支持邮件

当你导出 CSV / JSON 文件、创建结果卡片或使用系统分享面板时，目标位置由你选择。分享后，接收应用或服务会按其自身政策处理数据。

如果你发送支持邮件，开发者会收到你主动提供的邮箱地址、正文、附件与诊断信息。这些信息仅用于回复请求，并只在支持、安全与法律义务所需的期限内保留。发送前请移除密码、私钥及其他秘密信息。

5. 本网站

本静态网站不设置第一方 Cookie，也不包含广告或分析脚本。网站托管于 GitHub Pages。GitHub 说明，为安全目的会记录访问者的 IP 地址；相关处理适用 GitHub 隐私声明。

6. 保留与删除

你可以在应用内删除历史、已保存目标、预设、命令和相关记录。删除 SSH 目标时，Falcon 也会从钥匙串中移除与该目标关联的凭据。

卸载应用会移除其应用容器中的数据。钥匙串条目由操作系统管理，卸载后可能继续保留，因此 Falcon 无法保证仅通过卸载即可将其删除。已导出或分享的副本会继续保留在你选择的目标位置。

7. 儿童隐私

Falcon 是通用网络工具，并非面向儿童设计，也不会有意收集儿童的个人信息。

8. 政策变更

本政策如有变更，将在此发布更新版本并修改顶部日期。

9. 联系我们

如有隐私相关问题，请发送邮件至 boxing.support@gmail.com。
